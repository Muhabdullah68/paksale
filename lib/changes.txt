Women should be able to buy, sell, ask questions, and communicate without exposing their phone number, exact location, identity, or personal information unnecessarily.

1. Hide the Phone Number by Default

Never display a seller's or buyer's mobile number publicly.

Instead of:

📞 0300-1234567

Use:

Chat in App | Call Through App

The user can communicate without either person seeing the real number.

Better system
App-to-app chat
Masked calling/temporary number
Block user
Report user
No direct WhatsApp button by default

Recommended default: WhatsApp and personal phone numbers should be hidden unless the woman voluntarily chooses to share them.

2. Never Show the Exact Home Location

A woman selling an item from her home should not have to show her house location.

Display only:

or

House number
Street number
Exact GPS location
Apartment number
Exact live location

The seller can choose:

Location Options

🔵 City only — Lahore
